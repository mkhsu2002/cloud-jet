# Assets and dependencies

Updated: 2026-11-19.

All vehicle, track, gates, skyline, star, cloud and sun geometry/textures are generated by project-authored code in `src/world.ts`. Cloud and gate textures use the Canvas API. Engine and cue sounds are synthesized by project-authored Web Audio code in `src/audio.ts`. The favicon is project-authored SVG. Typography uses system fonts. These project assets are covered by the root MIT license.

Last Light’s score is a project-authored 32-bar stereo composition. The notation, synthesis, arrangement and rendering are defined in `scripts/compose.mjs`. `node scripts/compose.mjs` regenerates the bundled Ogg Opus file with FFmpeg. The game plays the bundled file, so FFmpeg is only needed to rebuild the score. No third-party recordings, samples, images, models, web fonts or logos are bundled. The game does not fetch remote content during a race. A reference to the competition in repository documentation does not imply official endorsement.

Runtime dependency: Three.js (MIT). Development dependencies include TypeScript (Apache-2.0), Vite (MIT), Vitest (MIT), Prettier (MIT) and Three.js type definitions (MIT); exact versions and transitive packages are pinned in package-lock.json.
