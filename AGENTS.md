# Cloud Jet development guardrails

Read README.md and docs/MVP.md before coding. Preserve the one-button mechanic: press to enter drift, hold to continue, release to boost. Mistakes affect elapsed time, never eligibility to finish. Begin with a single-bend vertical slice before expensive assets or a full track.

Codex is the primary implementation assistant. Use WebStorm for genuine debugging, inspection and test work; record only verified usage in docs/DEVELOPMENT_LOG.md. Never fabricate tool usage, dates, test passes or hackathon eligibility.

Keep deterministic simulation separate from rendering. Timestamp input, ignore key-repeat, reset on replay and handle blur. Test frame-rate independence and recovery paths. Choose a supported Node LTS when scaffolding and pin dependencies with a lockfile.

Do not commit secrets, personal machine paths, browser profiles, generated caches or local IDE workspace files. Do not deploy, submit an entry, purchase tools or add telemetry without authorization. Keep third-party assets and trademarks subject to their own licenses.
